# 机器人骑自行车：从运动技能习得到 World Model 的研究调研

**调研范围：截至 2026 年 11 月，重点关注机器人学习、强化学习、技能迁移、世界模型与运动控制。**

## 一、先说核心结论

我认为机器人骑自行车是一个很值得研究的载体，但最有价值的研究问题并不是：

> 如何通过强化学习，让机器人学会骑自行车？

而是三个更深层的问题：

1. **快速技能习得（Rapid Skill Acquisition）**：机器人能否像人一样，利用已经掌握的运动技能，快速学习一种具有不同动力学机制的新技能？
2. **跨任务动力学知识迁移（Transferable Dynamics Knowledge）**：走路、站立、抗扰动、平衡车、骑自行车之间，究竟有什么可以迁移？是策略、价值函数、动态状态表征，还是对物理世界的理解？
3. **世界模型的实际价值（World Model for Skill Learning）**：学习预测未来状态，究竟能否帮助机器人更快学会保持平衡？这种收益来自预测本身，还是利用预测进行规划、策略优化和在线适应？

这三个问题互相关联，而且可以形成一条完整的研究路线。

### 1.1 相关领域已经发展到什么程度？

首先，必须明确：**使用 RL 让机器人骑车已经不是一个全新的课题。**

我查到了几项尤其值得关注的工作：

| 论文 | 时间 | 主要贡献 | 与你的研究的关系 |
|---|---|---|---|
| Learning to Drive a Bicycle using RL and Shaping | ICML 1998 | 使用 SARSA 和奖励塑形学习自行车平衡、导航 | 早期基础研究 |
| Balancing Control of a Bicycle-Riding Humanoid Robot | 2018 | 小型人形机器人实际踩踏自行车，估计重心并保持平衡 | 真正的人形机器人骑车 |
| CycleRL | 2026 | PPO、Isaac Sim、域随机化，实现自主自行车 Sim-to-Real | 直接 RL 基线 |

| Ultra Mobility Vehicle（UMV） | 2026 | RL 控制自行车式机器人完成行驶、跳跃、单轮平衡等动作 | 多技能运动学习 |
| Scooter-Driving Humanoid Robot | 2026 | 全尺寸人形机器人利用 PPO 在真实双轮踏板车上保持平衡 | 人形机器人与双轮车辆结合 |

这些并非概念性设想，其中多项已经完成真实机器人实验。[ICML](https://icml.cc/Conferences/1998/papers/paper26.html?utm_source=chatgpt.com)

**但是，这些工作还没有充分回答你真正关心的一个问题：**

假设一个机器人已经熟练掌握站立、行走、抵抗外力、调整重心等技能，当我们让它学习骑自行车时，它能否显著比一个完全没有运动经验的机器人学得更快？

以及，假设两个机器人拥有完全相同的交互经验，但其中一个学到了可迁移的动力学世界模型，那么它能否利用这些知识更快掌握骑车？

这是我认为最值得继续挖掘的方向。

## 二、机器人骑自行车的研究现状

这里需要区分三种不同的研究对象：

- **自主自行车（Autonomous Bicycle）**：车本身是机器人，直接驱动车把和车轮。
- **人形机器人骑车（Humanoid Bicycle Riding）**：机器人坐在自行车上，通过双手、身体和双腿操作车辆。
- **自行车式动态机器人（Bicycle-like Robot）**：利用自行车的运动结构实现复杂动态行为，例如 UMV。

三者共享部分动力学问题，但研究难度和可迁移的知识不同。

### 2.1 人形机器人真正骑自行车：2018 年已有成果

**论文：Balancing Control of a Bicycle-Riding Humanoid Robot with Center of Gravity Estimation**

这是一项与你的目标直接相关的研究。

研究人员构建了小型人形机器人和相应尺寸的自行车，让机器人能够踩踏、转向和保持平衡。

关键技术是：

1. 建立机器人与自行车的耦合动力学模型。
2. 通过转动车把控制车辆横滚。
3. 在线估计机器人—自行车系统的不确定重心。
4. 根据重心估计结果进行自适应平衡控制。

论文提供了稳定性分析和真实机器人实验，但主要展示直线骑行，并不依赖视觉反馈。[Taylor & Francis Online](https://www.tandfonline.com/doi/abs/10.1080/01691864.2018.1509017?utm_source=chatgpt.com)

这项工作很重要，因为它揭示了一个问题：

**一个已经能够独立保持站立平衡的人形机器人，坐在自行车上以后，原来的平衡控制器并不能直接解决问题。**

站立主要利用脚底接触与关节力矩调整身体状态，而骑车需要通过车把控制轮胎接触点的运动，还要考虑前进速度对横滚动力学的影响。

因此，我们需要寻找的不是简单的“平衡策略迁移”，而是更抽象的动力学知识迁移。

### 2.2 CycleRL：目前很直接的 RL 基线

**论文：CycleRL: Sim-to-Real Deep Reinforcement Learning for Robust Autonomous Bicycle Control（2026）**

[项目主页与演示](https://cpnt-lab.github.io/CycleRL/?utm_source=chatgpt.com)

这项工作使用 Isaac Sim 训练自行车自主控制策略。

其基本结构为：

\[
o_t \xrightarrow{\pi_{\mathrm{PPO}}} a_t
\]

优化目标同时涉及：

\[
r_t =
r_{\mathrm{balance}}
+r_{\mathrm{velocity}}
+r_{\mathrm{heading}}
-r_{\mathrm{penalty}}
\]

这里是对论文奖励结构的概括，并非原文的完整奖励公式。

研究结果包括：

| 指标 | 结果 |
|---|---|
| 仿真平衡成功率 | 99.90% |
| 航向跟踪误差 | 1.15° |
| 速度跟踪误差 | 0.18 m/s |
| Sim-to-Real | 已进行实际硬件部署 |

论文利用域随机化提高对模型误差和实际不确定性的适应能力。以上精度数字来自仿真实验，不应直接当作真实硬件性能。[arXiv](https://arxiv.org/abs/2603.15013?utm_source=chatgpt.com)

**对你的启发：**

如果你的工作只是通过 PPO 学习自行车平衡，这篇论文已经提供了相当有竞争力的基线。

需要更进一步比较：

- 已有运动经验是否减少新任务交互次数？
- 学过动力学模型的机器人是否比纯策略迁移更快？
- 已经学会一种速度下骑车的模型，能否快速适应另一种速度范围？
- 预测与在线适应能否取代部分域随机化？

### 2.3 2026 年：RL 能在多大速度范围内学习骑车？

**论文：Path Following and Stabilization of a Bicycle Model Using a Reinforcement Learning Approach**

*Multibody System Dynamics, 2026*

[阅读论文](https://link.springer.com/article/10.1007/s11044-026-10144-x?utm_source=chatgpt.com)

这篇文章使用经典 Whipple 自行车动力学模型，以转向角设定值为主要控制输入，通过 RL 同时学习平衡和路径跟踪。

研究采用课程学习，能够在 **2–7 m/s** 的速度范围内完成包含圆周、蛇形路线与变道的任务。

它没有额外使用反作用轮或其他专用稳定机构。[Springer](https://link.springer.com/article/10.1007/s11044-026-10144-x?utm_source=chatgpt.com)

这说明从恒定速度到大范围变速骑行，本身就可以作为一个渐进学习任务。

但需要注意，课程学习实际上将不同速度下的任务组织在同一个训练过程中，并没有证明机器人已经掌握的**其他运动技能**可以迁移到骑车。

这两种能力应当严格区分。

### 2.4 UMV：2026 年最值得关注的自行车式机器人之一

**论文：System Design of the Ultra Mobility Vehicle: A Driving, Balancing, and Jumping Bicycle Robot**

[阅读论文](https://arxiv.org/abs/2602.22118?utm_source=chatgpt.com)



UMV 是 RAI Institute 等研究团队开发的自行车式动态机器人。

它不是人坐在车上的结构，而是通过专门设计的连接机构和可移动质量，在较少执行自由度下实现复杂动态运动。

机器人可以完成：

- 自主行驶和平衡；
- 原地平衡（Track Stand）；
- 抬前轮骑行（Wheelie）；
- 后轮跳跃；
- 跨越障碍物；
- 前空翻。

系统重量约 23.5 kg，论文报告最高速度达到 8 m/s，并能跳上约 1 m 高的障碍物。研究通过仿真训练实现多种行为的零样本实机迁移。[arXiv](https://arxiv.org/abs/2602.22118?utm_source=chatgpt.com)

更值得关注的是同一研究方向的两篇后续工作。

**第一篇：Bicycle Acrobatics with Reinforcement Learning（2026）**

这篇研究比较了不同运动技能的 RL 任务表述，包括：

- Waypoint Following
- Pose Reaching
- Twist Tracking
- Guided Tracking
- Motion Imitation

并通过状态触发机制切换多个策略，形成连续特技行为。[arXiv](https://arxiv.org/abs/2608.00880?utm_source=chatgpt.com)

**第二篇：LineRides: Line-Guided Reinforcement Learning for Bicycle Robot Stunts（RA-L 2026）**

[项目主页与视频](https://seungeunrho.github.io/LineRides/?utm_source=chatgpt.com)

它研究了一个非常值得注意的问题：

> 如果没有完整动作演示，只有空间路径和少量关键姿态，机器人能否学习复杂动态技能？

LineRides 使用空间引导线和关键姿态定义运动目标，不要求完整的时间对齐轨迹。

它还把同一训练框架应用到了四足机器人上。

**这里有一个需要区别的地方：LineRides 证明了任务描述和训练方法可以跨机器人形态复用，但并没有证明训练得到的具体动力学知识能够从自行车迁移给四足机器人。**[seungeunrho.github.io](https://seungeunrho.github.io/LineRides/?utm_source=chatgpt.com)

对你来说，这是一个很好的研究空缺：不仅迁移学习方法，更要迁移已经学到的知识。

### 2.5 人形机器人骑真实踏板车：2026 年的重要进展

**论文：Scooter-Driving Humanoid Robot: Sim-to-Real Transfer Through Deep Reinforcement Learning**

*Sensors, 2026 年 10 月*

[阅读完整论文](https://www.mdpi.com/1424-8220/26/19/6324?utm_source=chatgpt.com)

这项研究使用全尺寸人形机器人操作双轮踏板车，利用 PPO 训练平衡和转向控制。

其实验覆盖约 0.8–3.0 m/s 的低速范围。

部分实机结果如下：

| 任务 | 成功率 |
|---|---:|
| 直线行驶 | 96% |
| 小幅度转弯 | 92% |
| 急转弯 | 72% |
| 越过 60 mm 减速带 | 88% |
| 搭载约 70 kg 乘客 | 73% |
| 环岛路线 | 28% |

值得注意的是，模型只负责运动中的平衡与转向。速度目标、航向命令由人提供，油门由外部控制，起步和停车也需要人工操作。

因此，它不是完全自主骑行，但已经证明人形机器人可以通过学习控制真实双轮车辆。[MDPI](https://www.mdpi.com/1424-8220/26/19/6324?utm_source=chatgpt.com)

### 2.6 对这些工作的总体判断

目前的研究已经比较充分地证明：

**机器人可以通过 RL 或模型控制学会骑自行车、维持平衡、完成路径跟踪，甚至执行复杂特技。**

但是，以下问题仍然具有研究价值：

| 研究问题 | 现状判断 |
|---|---|
| 从零训练自行车平衡策略 | 已有较多研究 |
| 自行车 Sim-to-Real | 已有明确成果 |
| 自行车多技能学习 | 已有成果 |
| 不同速度之间迁移 | 已有课程学习研究 |
| 人形机器人操作真实双轮车辆 | 已有初步成果 |
| 将站立、行走等经验迁移到骑车 | **缺少直接、系统的验证** |
| 利用可迁移动力学 WM 快速习得骑车 | **具有研究空间** |
| 比较不同 WM 机制对骑车学习效率的因果作用 | **值得重点研究** |

这里的“缺少直接验证”是基于本次检索结果的判断，并非断言不存在任何相关工作。

## 三、人究竟是怎样学会骑自行车的？这对机器人学习有什么启发？

这是我认为值得认真研究，而不只是把人类学习过程当作类比的一部分。

### 3.1 一个很有意思的事实：平衡车训练可以促进自行车技能习得

有一类人类运动学习研究，与你希望研究的“技能迁移”高度相关。

**论文：Positive Skill Transfer in Balance and Speed Control from Balance Bike to Pedal Bike in Adults（PLOS ONE, 2024）**

研究人员让不会骑自行车的成年人先学习使用无脚踏的平衡车（Balance Bike），随后观察他们学习普通自行车的表现。

其中一个阶段采用八次、每次 20 分钟的平衡车训练。

研究发现，平衡车训练可以促进随后独立骑车技能的获得。训练涉及滑行、转弯、速度调整和动态平衡。([PLOS ONE](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0298142))

另外，一项 2025 年发表的儿童研究比较了平衡车与辅助轮自行车：

| 训练方式 | 后续独立骑车成功率 |
|---|---:|
| 平衡车 | 100% |
| 辅助轮自行车 | 76.92% |

这项研究共涉及 50 名儿童，采用准实验设计，因此结果有参考价值，但不能仅凭成功率差异就推断存在普遍的因果效果。[PubMed Central (PMC)](https://pmc.ncbi.nlm.nih.gov/articles/PMC11843937/?utm_source=chatgpt.com)

**这里的关键并不在于平衡车更容易，而在于它保留了目标任务的关键动力学结构。**

考虑两种先前训练经历：

**A. 使用辅助轮自行车**

训练者能够学习踩踏、转向等操作，但横向失衡通常受到辅助轮约束，不必真正学习通过转向恢复平衡。

**B. 使用平衡车**

训练者无需同时处理踩踏，但必须自己掌握速度、转向与横滚之间的耦合关系。

之后转移到普通自行车时，B 保留的经验可能更有价值。

这对机器人研究意味着：

> 不应该简单地问“预训练任务越多是不是越好”，而应该研究“什么样的源任务能够提供目标任务真正需要的动力学知识”。

这可以进一步发展成一个问题：

**能否在没有目标任务数据的情况下，预先判断两种运动技能之间的迁移价值？**

### 3.2 站立平衡和骑车平衡，本质上不是同一个控制问题

虽然两者都叫“平衡”，但可用控制动作不同。

人形机器人站立时，可以通过踝关节力矩、髋关节力矩、质心调整和迈步改变支撑关系。

自行车则存在特殊的横滚—转向耦合。

经典 Whipple 自行车模型可以在直立、直线运动附近线性化为：

\[
\boxed{
M\ddot q+vC_1\dot q+(gK_0+v^2K_2)q=f
}
\]

其中：

\[
q=
\begin{bmatrix}
\phi\\
\delta
\end{bmatrix}
\]

\(\phi\) 表示车体横滚角，\(\delta\) 表示转向角，\(v\) 是前进速度，\(f\) 是广义力输入。

这一模型显示，**自行车的横向动力学不仅取决于姿态，还显著依赖前进速度。**

而且，骑车控制经常具有反直觉的特征：当车体即将向一侧倒下时，需要通过恰当的转向运动调整接触点和运动轨迹，以恢复平衡。

经典研究还证明，陀螺效应和正拖距都不是自行车实现被动自稳定的必要条件，质量分布和转向几何等因素也起重要作用。[PubMed](https://pubmed.ncbi.nlm.nih.gov/21493856/?utm_source=chatgpt.com)

因此，如果直接把站立平衡的策略参数迁移到骑车任务，可能发生负迁移。

但这不代表两者没有共通知识。

它们可能共享的是：

| 可能共享的知识 | 迁移价值 |
|---|---|
| 重力对身体运动的影响 | 高 |
| 姿态、角速度与加速度的关系 | 高 |
| 惯性与角动量相关的动力学规律 | 高 |
| 扰动后的状态估计 | 高 |
| 身体关节运动对质心的影响 | 高 |
| 特定关节的平衡控制策略 | 不一定 |
| 特定接触结构下的动作—结果映射 | 可能很低 |
| 自行车转向与横滚的耦合规律 | 需要专门学习 |

**一个值得研究的假设是：动力学知识的可迁移程度，可能高于直接控制策略的可迁移程度。**

当然，这不是已经被证明的普遍规律。一个包含足够丰富动作和反馈历史的策略，也可能隐式学习类似的知识。

真正有意义的是比较这两种学习方式。

### 3.3 人类骑车还存在分层控制

2025 年的论文 *Modeling Human Steering Behavior Using a Custom Robotic Bicycle* 直接研究了人的骑车控制机制。

研究人员开发了带有传感器、可控力矩陀螺仪和主动转向的自行车，采集五位骑行者在横滚扰动下的反应。

他们使用级联 PID 结构近似人的转向与身体横滚控制行为，并将拟合得到的控制器用于闭环稳定。[ScienceDirect](https://www.sciencedirect.com/science/article/pii/S240589632502974X?utm_source=chatgpt.com)

这并不证明人脑就是 PID 控制器，但提示一个很有价值的结构：

\[
\text{运动目标}
\longrightarrow
\text{期望身体/车辆状态}
\longrightarrow
\text{快速稳定控制}
\]

机器人也不一定要用单个策略直接处理从导航到电机力矩的全部问题。

相反，可以让高层学习任务目标与动作选择，让低层学习平衡技能与动态适应。

对你要研究的 WM，我尤其建议考虑把**高频稳定控制与较低频的模型预测、更新和规划分开**。

## 四、能否从其他任务中学到骑车能力？已有研究最接近哪一步？

这一部分比自行车论文更重要，因为它决定你的研究是否只是一个新的 RL 应用场景。

### 4.1 LocoFormer：最值得重点阅读的跨运动技能研究

**LocoFormer: Generalist Locomotion via Long-Context Adaptation（CoRL 2025）**

[项目主页、论文与演示](https://generalist-locomotion.github.io/?utm_source=chatgpt.com)

这是我认为与你的研究目标最接近的工作之一。

它的目标并不是对每一种机器人重新训练一套运动策略，而是训练一个能够控制不同形态机器人的通用运动模型。

它采用两个关键设计。

**第一，大规模跨形态预训练。**

通过程序化生成多种机器人形态并进行域随机化，让策略接触大量不同的运动动力学。

**第二，跨多个试验保留长历史。**

利用 Transformer-XL 形式的记忆，使模型不仅根据当前观测决策，还能利用此前失败和成功的交互记录。

因此，当机器人第一次遇到某种新的身体结构时，它可以通过执行过程推断这个身体应该怎样控制。

比较有意思的是，模型能够在前几次试验中失败，并在后续试验中改善控制行为。

论文展示了不同足式和轮式机器人上的泛化与快速适应。[Proceedings of Machine Learning Research](https://proceedings.mlr.press/v305/liu25a.html?utm_source=chatgpt.com)

**这里存在一个值得你直接借鉴的问题：**

LocoFormer 的成功一定需要显式世界模型吗？

不需要。

它利用历史上下文和大规模训练，使策略隐式完成系统辨识与动作适应。

可以将其抽象为：

\[
a_t=\pi(o_t,h_t,g_t)
\]

其中：

\[
h_t=f(o_{<t},a_{<t})
\]

历史 \(h_t\) 包含对未知动力学的隐式估计。

这产生了一个非常强的对照组：

\[
\boxed{
\text{历史条件策略}
\quad\text{vs}\quad
\text{显式动力学世界模型}
}
\]

如果你准备研究 WM 的作用，必须与这种能够从历史中推断动力学的策略比较，而不应该只拿一个没有记忆的 MLP 作为对照。

否则，WM 的收益可能只是来自它额外获得了历史信息。

### 4.2 RMA：机器人可以快速估计未知动力学条件

**RMA: Rapid Motor Adaptation for Legged Robots（RSS 2021）**

[论文](https://www.roboticsproceedings.org/rss17/p011.html?utm_source=chatgpt.com)

RMA 使用一个基础运动策略和一个适应模块。

适应模块从历史传感器数据中估计反映当前环境动力学特征的隐变量：

\[
z_t=f_\phi(o_{t-H:t},a_{t-H:t-1})
\]

策略根据这一隐变量产生动作：

\[
a_t=\pi_\theta(o_t,z_t)
\]

RMA 可以在很短时间内适应地面变化、负载变化等动力学条件，并完成真实四足机器人部署。

它的重要意义在于：

**对于很多机器人控制任务，我们未必需要显式预测整个未来状态，只需要从历史中推断影响当前控制的动力学参数。**[Robotics Proceedings](https://www.roboticsproceedings.org/rss17/p011.html?utm_source=chatgpt.com)

例如，机器人骑车时可能需要在线推断：

\[
z_t=
[
m_{\mathrm{rider}},
h_{\mathrm{CoM}},
I_{\mathrm{roll}},
\mu_{\mathrm{tire}},
\tau_{\mathrm{steering}},
\ldots
]
\]

这里的变量是研究设计中的示例，不是 RMA 原论文采用的自行车参数。

这种机制很适合应对更换自行车、改变载荷、调节轮胎摩擦等情况。

不过，RMA 主要解决的是**已有技能在变化动力学条件下的快速适应**，而不是从站立直接学会骑车。

### 4.3 URMA：运动控制策略可能存在跨形态的抽象层

**One Policy to Run Them All: An End-to-end Learning Approach to Multi-Embodiment Locomotion（CoRL 2024／2025 年论文集）**

这项研究使用形态无关的编码器和解码器，将不同机器人的状态、动作映射到共享潜空间。

它尝试学习一个可跨机器人形态使用的抽象运动控制策略。[Proceedings of Machine Learning Research](https://proceedings.mlr.press/v270/bohlinger25a.html?utm_source=chatgpt.com)

另一篇值得关注的是：

**Transferable Latent-to-Latent Locomotion Policy for Efficient and Versatile Motion Control of Diverse Legged Robots（2025）**

它预训练共享潜空间策略，再通过任务专用编码器和解码器适应新任务与新机器人。[arXiv](https://arxiv.org/abs/2503.17626?utm_source=chatgpt.com)

这类研究启发了一个可能的设计：

\[
\begin{aligned}
z_t &= E_{\text{task}}(o_t)\\
u_t &= \pi_{\text{shared}}(z_t,g_t)\\
a_t &= D_{\text{task}}(u_t)
\end{aligned}
\]

例如，站立和骑车的动作空间虽然不同，但中间潜在控制命令可以表达为：

- 需要的身体横滚修正；
- 期望的角动量变化；
- 期望质心运动；
- 期望的接触反作用。

不同任务通过各自的动作解码器，实现这些共同的控制目标。

但需要特别谨慎：

**如果站立和骑车采用的控制通道不同，共享的抽象命令并不一定都可实现。**

例如，机器人站在地面时可以通过改变脚底压力中心调整横滚，而自行车可能需要先转向才能产生所需的横向运动。

所以，共享动作空间必须结合当前系统的可控性与执行能力设计，而不是仅通过表示对齐强迫不同动作具有相同含义。

### 4.4 我认为最有价值的迁移研究，不是单纯的 Policy Transfer

跨任务学习至少可以区分四个层次：

| 迁移对象 | 学到什么 | 可能的局限 |
|---|---|---|
| Policy Transfer | 直接使用已有的状态—动作映射 | 动作空间和动力学变化可能导致负迁移 |
| Representation Transfer | 迁移姿态、运动、接触等状态表征 | 表征相似不保证控制知识可用 |
| Dynamics Transfer | 迁移状态转移规律和动力学先验 | 新接触结构与新执行器可能改变动力学 |
| Learning-to-Learn | 迁移系统辨识、探索和策略更新能力 | 需要覆盖足够广的训练任务分布 |

对于机器人骑车，后两种尤其值得研究。

具体来说：

> 一个机器人是否能够通过站立、行走、被推动、重心调整等任务，学到某种通用的物理状态转移规律，并将其用于快速理解自行车这一新系统？

这个问题比“能不能从站立策略初始化骑车策略”更有研究深度。

它也更适合引入 World Model。

## 五、World Model 能否真正帮助机器人快速学会骑车？

这可能是整项研究中最有理论价值、也最容易出现错误结论的部分。

我查到了两类特别值得关注的证据：一类来自对人类骑车控制的研究，另一类来自 Model-Based RL。

### 5.1 人类骑车控制中，已经有使用内部预测模型的证据

**Rider Control Identification in Cycling Taking into Account Steering Torque Feedback and Sensory Delays（2022）**

这篇论文值得重点阅读。

研究人员采集了不同骑行速度下人类应对平衡扰动的数据，并建立考虑感知延迟的骑行者控制模型。

其中提出一种利用内部前向模型（Internal Forward Model）补偿感知延迟的控制结构。

研究发现，简单加入感知延迟而不进行前馈补偿的模型，难以解释实验中观察到的人类控制反应；引入预测机制后，模型能更好地拟合这些响应。[Taylor & Francis Online](https://www.tandfonline.com/doi/full/10.1080/00423114.2022.2048865?utm_source=chatgpt.com)

这与你关心的 WM 非常相关。

考虑机器人骑车时的控制延迟：

\[
s_t \xrightarrow{\text{感知、计算、执行延迟}}
a_{t+\Delta}
\]

如果控制器只能根据旧状态决策，那么对于快速变化的横滚状态，可能已经错过合适的控制时机。

一个具有状态预测能力的控制器可以估计：

\[
\hat s_{t+\Delta}
=
f_\theta(s_t,a_{t:t+\Delta})
\]

随后根据预测的未来状态决策：

\[
a_{t+\Delta}
=
\pi(\hat s_{t+\Delta})
\]

这提供了比“预测未来有利于学习”更明确的机制假设：

**预测未来状态可以补偿传感与执行延迟，从而改善不稳定系统的反馈控制。**

但这仍然不意味着使用神经网络世界模型一定优于传统状态观测器或解析动力学模型。它们应该成为你的对照方法。

### 5.2 DayDreamer：WM 已经帮助真实机器人从零学习运动技能

**DayDreamer: World Models for Physical Robot Learning（CoRL 2022）**

这是非常值得复现或借鉴的一项研究。

研究直接在真实机器人上使用 Dreamer，不依赖事先构建的仿真环境。

其中，四足机器人在约一小时内，从零学习了翻身、站立和行走。面对随后施加的扰动，模型还能够在约十分钟内继续适应。

它也在机械臂操作和轮式机器人导航任务上进行了实验。[Proceedings of Machine Learning Research](https://proceedings.mlr.press/v205/wu23c.html?utm_source=chatgpt.com)

DayDreamer 的核心思路是：

\[
\text{真实交互}
\rightarrow
\text{学习 World Model}
\rightarrow
\text{想象未来轨迹}
\rightarrow
\text{优化策略}
\]

真正减少交互成本的是：**模型能够利用已经采集的真实经验，生成供策略优化使用的模拟经验。**

这与仅仅给策略添加一个未来预测损失存在本质区别。

### 5.3 必须区分 WM 的四种作用

建议把你想研究的 WM 拆分为四种机制。

| WM 使用方式 | 主要机制 | 对骑车任务的潜在价值 |
|---|---|---|
| Auxiliary Prediction | 预测损失改善状态表征 | 帮助学习动力学相关特征 |
| Imagination Learning | 利用预测轨迹训练 Actor/Critic | 减少真实交互样本 |
| Model Predictive Control | 根据预测结果选择动作 | 提高平衡控制和抗扰能力 |
| Online System Identification | 根据新经验修正动力学模型 | 快速适应陌生自行车 |

这四种机制不应该混在同一个实验中，否则即使最后效果很好，也无法解释为什么有效。

#### A. 只使用未来预测损失

例如：

\[
\hat s_{t+1}=f_\theta(s_t,a_t)
\]

训练：

\[
\mathcal L_{\mathrm{WM}}
=
\mathbb E
\left[
\|\hat s_{t+1}-s_{t+1}\|^2
\right]
\]

然后把 WM 学到的表征输入策略：

\[
a_t=\pi(s_t,z_t)
\]

这种方法可以作为一个基线，但我不建议把它作为主要贡献。

原因是：

**预测状态更准确，并不自动意味着控制策略更优秀。**

例如，某个 WM 很准确地预测了车轮转速，但没有充分捕捉接近失衡边界时的转向响应，它依然可能是很差的平衡控制模型。

#### B. 利用 WM 进行想象训练

这类方法更接近 Dreamer。

我们可以从真实状态 \(s_t\) 出发，在 WM 中展开：

\[
\hat s_{t+1}=f_\theta(s_t,a_t)
\]

\[
a_{t+1}\sim \pi(\cdot\mid \hat s_{t+1})
\]

\[
\hat s_{t+2}
=f_\theta(\hat s_{t+1},a_{t+1})
\]

然后通过这些预测轨迹更新策略或价值函数。

这里的直接收益是用计算换取真实交互次数。

**但它的主要问题是模型误差累积。**

MBPO 的研究表明，从真实状态出发使用较短的模型 rollout，能够在一定程度上兼顾样本效率与模型误差；过长的 rollout 反而可能损害策略学习。[NeurIPS Proceedings](https://proceedings.neurips.cc/paper/2019/hash/5faf461eff3099671ad63c6f3f094f7f-Abstract.html?utm_source=chatgpt.com)

对于自行车这样的不稳定系统，预测误差可能尤其危险。

举个例子：

真实自行车可能已经向左倾斜到难以恢复的状态，但世界模型预测它仍然可以恢复平衡。

如果策略持续利用这种错误预测训练，最后学到的可能是一套只在 WM 内能够成功的控制行为。

因此，应当同时研究：

\[
\text{模型预测不确定性}
\rightarrow
\text{可置信的预测时域}
\rightarrow
\text{安全的策略优化}
\]

#### C. WM + MPC

我认为这一方向具有很明确的物理意义。

设：

\[
\hat s_{t+k+1}
=f_\theta(\hat s_{t+k},a_{t+k})
\]

控制器求解：

\[
\min_{a_{t:t+H-1}}
\sum_{k=0}^{H-1}
\ell(\hat s_{t+k},a_{t+k})
+V_f(\hat s_{t+H})
\]

其中代价函数包含横滚、路径误差、控制力矩和动作变化等。

这个机制允许控制器比较：

“如果现在向左转，未来会怎样？”

“如果向右转，车辆会怎样？”

“哪一种动作能在接下来一小段时间内保持稳定？”

与只预测一条未来轨迹不同，MPC 利用模型评估**不同候选动作的后果**。

这是 WM 与决策之间比较直接的联系。

不过，在高频平衡任务中，MPC 的计算延迟、预测偏差和安全约束处理都必须实际测量。

#### D. WM 用于在线动力学适应

这是我最推荐重点探索的方向之一。

假设机器人已经能够骑自行车 A，现在给它一辆新的自行车 B。

B 的重心位置、质量、转向惯性和轮胎特性都不同。

机器人是否能够通过少量交互快速学习这些差异？

可以采用：

\[
\hat\theta_t
=
g_\phi(s_{0:t},a_{0:t-1})
\]

其中 \(\hat\theta_t\) 表示在线估计的动力学参数或潜在动力学表征。

再通过：

\[
\hat s_{t+1}
=
f_\psi(s_t,a_t,\hat\theta_t)
\]

预测新的系统响应。

这种方式使机器人不必从头训练全部控制策略，而是通过修正当前系统的动力学认识实现适应。

## 六、WM 究竟应该学习什么？这里有一个值得研究的理论问题

你之前关注过一个很关键的问题：**为什么未来观测预测应该有利于下游任务？**

在自行车任务中，可以更清楚地分析这个问题。

### 6.1 我建议从控制相关预测，而不是图像预测入手

假设使用仿真中的真实状态：

\[
s_t=
[
\phi,\dot\phi,
\delta,\dot\delta,
v,\psi,
q_{\mathrm{robot}},
\dot q_{\mathrm{robot}},
\ldots
]
\]

其中包含车体横滚、转向状态、速度、航向，以及机器人的关节状态。

可以先研究：

\[
p(s_{t+1}\mid s_t,a_t)
\]

而不是直接：

\[
p(o_{t+1}^{\mathrm{image}}\mid o_t,a_t)
\]

原因很简单：自行车稳定主要取决于动力学状态，图像生成不是这个阶段的关键瓶颈。

如果低维状态预测都无法产生可验证的学习收益，那么引入更复杂的视觉 WM 可能只会增加实验难度。

### 6.2 预测误差与任务价值不等价

这里有两篇特别值得关注的理论研究。

**The Value Equivalence Principle for Model-Based Reinforcement Learning（NeurIPS 2020）**

它讨论了一个重要问题：

世界模型不一定需要准确还原环境的全部状态转移；对于价值规划而言，更重要的是模型能否产生正确的 Bellman 更新。

因此，在特定策略与价值函数集合下，两个动力学模型即使预测不同，也可能在价值意义上等价。[NeurIPS Proceedings](https://proceedings.nips.cc/paper_files/paper/2020/hash/3bb585ea00014b0e3ebe4c6dd165a358-Abstract.html?utm_source=chatgpt.com)

另一篇是：

**DeepMDP: Learning Continuous Latent Space Models for Representation Learning（ICML 2019）**

它研究通过奖励预测和潜在状态转移预测建立控制相关表征，并分析与状态抽象、价值函数之间的理论联系。[Proceedings of Machine Learning Research](https://proceedings.mlr.press/v97/gelada19a.html?utm_source=chatgpt.com)

这两项工作为你的研究提供了明确的理论基础。

你可以提出：

> 对于快速习得骑车平衡，究竟是具有最低状态预测误差的 WM 更有效，还是能够更准确判断未来动作价值与失稳风险的 WM 更有效？

两者并不一定一致。

### 6.3 可以考虑任务相关的 WM 损失

一个实验性设计是：

\[
\mathcal L
=
\lambda_1\mathcal L_{\mathrm{dyn}}
+
\lambda_2\mathcal L_{\mathrm{value}}
+
\lambda_3\mathcal L_{\mathrm{safety}}
\]

其中：

**动力学预测损失**

\[
\mathcal L_{\mathrm{dyn}}
=
\|\hat s_{t+1}-s_{t+1}\|^2
\]

**价值相关损失**

让模型在真实采样动作附近产生的 Bellman 备份与参考目标一致，例如：

\[
\mathcal L_{\mathrm{value}}
=
\left(
\hat r_t+
\gamma V(\hat s_{t+1})
-y_t
\right)^2
\]

其中 \(y_t\) 可以由真实环境转移构造，并在训练时适当处理目标网络和梯度传播。

**安全相关损失**

可以关注失稳边界预测：

\[
\mathcal L_{\mathrm{safety}}
=
\operatorname{BCE}
\left(
\hat p_{\mathrm{fall}},
y_{\mathrm{fall}}
\right)
\]

这里 \(y_{\mathrm{fall}}\) 可以表示在指定时域、给定后续控制策略下是否失稳。

这只是一个候选研究设计，不能直接声称上述损失组合具有理论性能保证。

我尤其看好将 WM 用于：

**预测系统是否即将进入难以恢复的失衡状态。**

因为这比预测所有状态细节更接近机器人真正需要解决的问题。

还需要注意，某一状态是否可恢复，不只取决于状态本身，也取决于允许采用的动作、执行器能力和后续控制策略。

因此，安全预测最好能够进一步与可恢复域或可行控制集合联系起来。

## 七、如果实际开展研究，我建议怎样设计实验？

这一部分尽量兼顾研究价值与工程可行性。

### 7.1 不建议一开始就做完整人形机器人踩踏自行车

完整人形骑车需要同时解决：

- 双手与车把的稳定接触；
- 双腿周期性踩踏；
- 身体重心调整；
- 自行车横滚与转向耦合；
- 起步、低速和停车；
- 摔倒后的恢复与安全问题。

如果一开始就把这些因素全部引入，即使训练失败，也很难判断问题究竟发生在哪一层。

我建议按照三个阶段推进。

| 阶段 | 机器人系统 | 研究重点 |
|---|---|---|
| 第一阶段 | 自主自行车，控制转向与后轮驱动 | 快速平衡学习与 WM |
| 第二阶段 | 坐在车上的机器人，控制车把与身体姿态 | 动力学迁移和身体—车辆耦合 |
| 第三阶段 | 具有踩踏能力的人形机器人 | 多技能组合与复杂运动学习 |

第一阶段可以建立比较严格的机器学习实验。

第二阶段才开始真正回答“人形机器人原有的平衡技能能否迁移到自行车”。

第三阶段则进一步研究如何整合不同技能。

### 7.2 第一组实验：什么样的预训练最有价值？

我建议设计这样一个实验。

**目标任务：**

机器人从给定初始速度开始，学习通过转向保持自行车平衡。

**预训练条件：**

| 实验组 | 预训练任务 | 想验证的问题 |
|---|---|---|
| A | 无预训练 | 从零学习基线 |
| B | 倒立摆平衡 | 基础平衡经验能否迁移 |
| C | 轮式倒立摆运动控制 | 带有运动动力学的平衡经验是否更有效 |
| D | 自行车无脚踏滑行平衡 | 共享关键动力学结构是否重要 |
| E | 多种质量、重心、惯性系统的平衡与抗扰任务 | 多样动力学经验是否产生更通用的知识 |

这里有一个很有意思的假设：

**D 组可能明显优于 B 组，但 E 组有可能在面对不同自行车结构时具有更好的泛化能力。**

不能预设结果一定如此，尤其需要检验某些源任务是否产生负迁移。

更重要的是，还要比较预训练究竟迁移了什么。

例如，在相同的源任务数据上分别训练：

\[
\text{Policy Prior}
\]

\[
\text{Representation Prior}
\]

\[
\text{Dynamics Prior}
\]

然后进入同一个自行车任务。

如果 Dynamics Prior 在早期学习阶段具有明显优势，就可以进一步分析这种优势来自哪里。

### 7.3 第二组实验：WM 是否真的提高学习效率？

这组实验应当是核心实验之一。

保持机器人、奖励、任务、观测和目标任务数据预算尽可能一致。

比较：

| 方法 | 使用历史 | 学习动力学 | 使用模型辅助决策 |
|---|---|---|---|
| PPO / SAC | 可不使用 | 否 | 否 |
| Recurrent PPO / SAC | 是 | 隐式 | 否 |
| PPO + Auxiliary WM | 是 | 是 | 否 |
| MBPO | 是 | 是 | 想象数据训练 |
| DreamerV3 | 是 | 是 | 想象轨迹优化 |
| TD-MPC2 | 是 | 是 | 潜空间规划 |
| Task-Aware WM | 是 | 是 | 根据设计选择 |

DreamerV3 和 TD-MPC2 都已有比较充分的通用连续控制研究基础。

TD-MPC2 的论文在 104 项在线 RL 任务上进行了实验，并展示了跨任务与机器人形态的模型扩展能力。[ICLR Proceedings](https://proceedings.iclr.cc/paper_files/paper/2024/hash/cf73d57b6dcda32b293df7c2d5341f49-Abstract-Conference.html?utm_source=chatgpt.com)

这里需要区分两种实验设置。

**设置 A：不进行预训练。**

所有方法从零开始学习自行车控制。

这个实验检验 WM 能否改善目标任务本身的样本效率。

**设置 B：进行跨任务预训练。**

先让模型学习其他动力学任务，再使用相同的自行车交互预算进行适应。

这个实验检验 WM 中的知识是否具有可迁移性。

这两个结论不能互相替代。

另外，对预训练模型还应该比较冻结参数、部分微调和完全微调，防止把额外参数量或额外训练计算误认为迁移收益。

### 7.4 第三组实验：像人一样从失败中快速适应

这是我认为最可能做出有特色结果的实验。

设想机器人已经学会骑自行车，现在替换一辆动力学不同的新车。

例如：

\[
m'=m+\Delta m
\]

\[
I'=I+\Delta I
\]

\[
\mu'=\mu+\Delta\mu
\]

或者改变车辆几何、转向执行器延迟与控制增益。

机器人最初不知道这些变化。

你允许它进行有限次数的尝试，例如 1、3、5、10 次，并在每次尝试后记录策略表现。

比较三类方法：

**方法 A：普通策略**

仅根据当前观测决策。

**方法 B：历史条件策略**

类似 LocoFormer，通过跨试验历史推断新的系统行为。

**方法 C：具有在线更新能力的 WM**

通过先前交互修正对动力学的估计，再辅助控制或策略更新。

核心评估：

\[
\boxed{
\text{成功率}
=
f(\text{目标任务交互次数})
}
\]

同时统计第一次成功前经历多少次失败、达到目标稳定性需要多少真实交互数据，以及受到外力干扰后的恢复能力。

如果 WM 方法仅仅在训练中表现更好，却没有减少真实交互次数，那么它还没有解决最初的“快速学习”问题。

### 7.5 第四组实验：预测准确性是否等于学习能力？

这个实验可以直接回应你对 WM 的理论质疑。

训练几种不同的世界模型：

| 模型 | 优化目标 |
|---|---|
| WM-A | 单步状态预测 |
| WM-B | 多步状态预测 |
| WM-C | 状态预测 + 奖励/价值相关监督 |
| WM-D | 状态预测 + 失稳风险监督 |
| WM-E | 结构化动力学 + 学习残差 |

分别评价：

\[
E_{\mathrm{prediction}}
\]

以及：

\[
J_{\mathrm{control}}
\]

重点观察：

**预测误差更低的模型，是否一定能够帮助机器人更快学会骑车？**

尤其可以测试接近失稳边界的状态。

一个模型在普通直线骑行数据上预测得很好，不代表它能够准确判断紧急情况下哪一种动作可以恢复平衡。

这正是模型预测指标与控制性能可能不一致的地方。

2026 年关于物理 AI 世界模型的综述也强调，需要考虑模型误差累积、规划器利用模型错误、预测不确定性和闭环决策性能，而不能只报告离线预测指标。[Springer](https://link.springer.com/article/10.1007/s44163-026-02122-1?utm_source=chatgpt.com)

## 八、我最推荐的技术路线：可迁移动力学模型 + 在线适应

如果要从以上问题中选择一个主要技术方案，我更倾向于研究**结构化的可迁移动力学世界模型**。

### 8.1 为什么不直接使用完全黑盒的神经网络？

例如直接学习：

\[
s_{t+1}=f_\theta(s_t,a_t)
\]

这种方法最容易实现，但跨任务迁移时可能遇到问题。

站立任务和骑车任务的执行器、接触约束、动力学维数都可能不同。

一个只接受固定长度状态和动作向量的模型，不一定能自然迁移。

因此，可以考虑将系统表示为：

\[
\text{机器人本体}
+
\text{外部对象}
+
\text{接触关系}
+
\text{动力学参数}
\]

而不是把整个系统当成一个没有内部结构的大向量。

### 8.2 Physics Prior + Learned Residual

一个可落地的起点是：

\[
\boxed{
\hat s_{t+1}
=
F_{\mathrm{physics}}(s_t,a_t;\hat\theta_t)
+
\Delta F_\phi(s_t,a_t,h_t)
}
\]

其中：

- \(F_{\mathrm{physics}}\)：基于已知物理结构构建的动力学预测；
- \(\hat\theta_t\)：根据当前交互估计的系统参数；
- \(\Delta F_\phi\)：学习传统模型未能解释的动力学残差；
- \(h_t\)：用于推断未知动力学的历史信息。

需要保证残差的输出处于合适的状态空间中。对于姿态等非欧氏状态，不能在任意坐标下简单相加。

这一设计具有几个潜在好处。

首先，机器人不必重新学习所有基础物理规律。

其次，可以利用已有物理模型提供较好的初始预测。

最后，在接触、摩擦、载荷等变化时，学习模块可以调整预测结果。

当然，这也引入了物理先验错误和结构限制，因此必须与纯神经动力学模型进行比较。

### 8.3 不只学习预测，还要学习怎样利用预测

一个建议的系统结构是：

```text
              历史状态与动作
                    │
                    ▼
              Dynamics Encoder
                    │
                    ▼
             动力学隐变量 z_t
                    │
        ┌───────────┴───────────┐
        ▼                       ▼
    World Model             当前状态 s_t
        │                       │
        ▼                       │
   预测候选动作后果              │
        │                       │
        ▼                       ▼
   风险 / 价值评估 ─────────► 控制策略
                                │
                                ▼
                             执行动作
                                │
                                ▼
                             真实反馈
```

这里的 Dynamics Encoder 可以跨任务预训练。

World Model 可以通过新任务少量数据适应。

控制器则负责将已经学到的知识转换为实际动作。

这是一个候选研究架构，而不是已有论文中完整验证过的系统。

我认为真正值得研究的不是把这些模块全部堆叠起来，而是逐步证明：

\[
\text{动力学迁移}
\Rightarrow
\text{更准确的目标任务初期预测}
\]

以及：

\[
\text{更有用的预测}
\Rightarrow
\text{更高的决策质量}
\]

最终：

\[
\boxed{
\text{减少学会新技能所需的真实交互}
}
\]

这三个因果环节分别需要实验支持。

## 九、具体实现：从什么仿真环境开始？

我建议先使用**低维状态输入的 MuJoCo 自行车模型**，把复杂度集中在动力学迁移与 WM 上。

### 9.1 第一阶段的仿真模型

至少包含：

| 组件 | 作用 |
|---|---|
| 自行车车架 | 刚体姿态与惯量 |
| 前后车轮 | 转动动力学与地面接触 |
| 转向关节 | 横向平衡控制 |
| 后轮驱动 | 前进速度控制 |
| IMU 类观测 | 横滚姿态与角速度 |
| 关节状态 | 转向角、转向速度与轮速 |
| 外部扰动 | 检验抗扰与恢复 |
| 参数随机化 | 检验快速适应与泛化 |

可以利用 Whipple 模型检查仿真结果是否具有合理的横向动力学响应。

推荐两个工具：

**BicycleParameters**

用于计算和分析自行车动力学参数，以及经典 Whipple 模型。

[BicycleParameters GitHub](https://github.com/moorepants/BicycleParameters?utm_source=chatgpt.com)

需要注意，它是动力学参数分析工具，不是可以直接运行完整 RL 任务的自行车仿真环境。

**Autonomous Bike RL**

这是一个采用 MATLAB/Simulink 和 Simscape Multibody 的开源自行车强化学习项目，包含车体动力学与方向控制。

[Autonomous Bike RL GitHub](https://github.com/vjardimb/autonomous-bike-rl?utm_source=chatgpt.com)

如果希望快速研究经典控制与 RL 的差异，这个项目可能比较适合作为参考。

对于 MuJoCo，需要自行构建或适配模型，并验证轮地接触、侧向滑移和转向响应。不能仅凭机器人在仿真中保持直立，就认定自行车动力学准确。

### 9.2 实验中必须注意低速问题

**零速平衡和高速动态平衡不是同一个难度等级。**

自行车前进速度降低时，通过转向控制横滚的机制与有效控制能力会发生变化。

某些自行车可以在特定速度区间表现出被动稳定性，但这不能推广到全部速度或几何配置。

如果机器人需要原地保持平衡，就可能必须使用身体重心移动、反作用轮等其他控制机制，或者通过允许一定范围内的前后运动维持动态稳定。

因此，建议将任务分为三个速度阶段：

| 阶段 | 控制问题 |
|---|---|
| 中速稳定骑行 | 学习基本横滚—转向耦合 |
| 变速骑行 | 学习速度相关动力学 |
| 低速与停车 | 学习新的平衡策略和控制模式 |

不要一开始就要求机器人在零速状态下只通过转动车把保持直立。

此外，2025 年的 LPV 自行车控制研究已经在变速条件下实现较好的横滚跟踪表现，适合作为传统控制基线。[ScienceDirect](https://www.sciencedirect.com/science/article/pii/S0967066125003661?utm_source=chatgpt.com)

### 9.3 真实硬件实验中的安全设计

如果后续进入实机，建议使用限位保护、吊挂或辅助支撑结构，记录它们是否在实验中产生了实际支撑力。

否则，辅助机构可能悄悄改变平衡任务的动力学。

尤其需要明确区分：

**带有辅助机构但未介入控制**，和**依赖辅助机构防止摔倒**。

对于少样本在线学习，这种安全设计非常重要，因为机器人必须允许失败，但不应该每次失败都造成硬件损坏。

## 十、怎样把这项研究做成有说服力的论文？

我认为最值得考虑的不是提出一个包含大量模块的复杂算法，而是确立一个明确、可检验的问题。

### 方向 A：跨任务平衡知识迁移

**研究问题：哪些运动经验能够帮助机器人更快习得新的平衡技能？**

实验核心是比较不同源任务的正迁移和负迁移。

可能的主要贡献是发现不同动力学结构之间的可迁移规律。

这个方向的优点是问题明确，实验容易设计，而且不依赖必须提出一种全新的网络架构。

但如果最终仅发现“相似任务预训练更有效”，学术贡献可能不够，需要进一步解释相似性究竟体现在哪些动力学性质上。

### 方向 B：用于快速运动学习的 Task-Aware World Model

**研究问题：为什么某些状态预测能够提高控制学习效率，而另一些不能？**

重点比较未来状态预测、价值相关预测和失稳风险预测。

这一方向更贴近你此前关注的 WM 有效性问题。

如果能够说明某种可测量的动力学预测性质，与下游控制能力和学习速度具有稳定关系，就有机会获得更强的研究结论。

但需要防止只在特定奖励函数上得到结果。

### 方向 C：跨任务预训练 WM + Few-Shot Skill Acquisition

**研究问题：机器人能否利用其他运动任务中形成的动力学知识，在极少的新任务交互下学会骑车？**

这是我最推荐的整体方向。

可以考虑一个工作标题：

**Learning to Ride: Transferable Dynamics World Models for Rapid Acquisition of Unseen Motor Skills**

中文可以理解为：

**Learning to Ride：利用可迁移动力学世界模型快速习得未知运动技能**

这不是已有论文名称，而是一个研究选题建议。

它的主要研究假设可以归纳为：

\[
\boxed{
\text{源任务动力学经验}
+
\text{目标任务少量交互}
\rightarrow
\text{快速习得新技能}
}
\]

这里又可以研究两个问题：

**H1：可迁移的动力学知识能否提高目标任务的数据效率？**

**H2：使用显式动力学预测进行适应，是否比历史条件策略中的隐式适应更有效？**

为了避免结论被其他因素混淆，需要控制源任务数据量、目标任务真实交互预算、网络容量和训练计算量，并至少进行多个随机种子的重复实验。

最好同时报告达到特定成功率所需的样本数、真实失败次数、总训练计算和最终性能。

这样才能区分真正的样本效率提升与额外计算带来的收益。

# 十二、最后的研究判断

经过这次调研，我认为可以比较明确地作出以下判断。

### 1. 骑自行车已经不是一个足够新颖的 RL 任务

不论是自主自行车，还是人形机器人操作双轮车辆，都已经有实机成果。

如果研究主要贡献是设计奖励、利用 PPO 训练成功，再完成 Sim-to-Real，那么需要面对已有较成熟的相关工作。

### 2. “快速学会骑车”仍然是值得研究的问题

尤其是：

**一个已经学会多种运动技能的机器人，是否真的应该比没有先前经验的机器人更快学会骑车？**

这是一个很好的研究问题。

但不能预先认定答案一定是肯定的。

不同技能之间可能存在正迁移，也可能由于控制机制不同而出现负迁移。

### 3. 平衡能力可能并不是可直接迁移的完整技能

人从站立到骑车，可能不是简单复用了同一个平衡控制器。

更值得研究的是，人能否复用此前建立的动力学认识、状态估计能力、运动预测能力和系统适应能力。

机器人研究可以将这些能力分开测量。

### 4. WM 的贡献必须建立在明确的作用机制上

我不建议提出：

> 机器人通过预测未来状态学习更好的表征，因此更快学会骑车。

这个假设太宽泛，难以充分论证。

更强的研究问题是：

> 机器人通过跨任务获得的动力学知识，能否在面对新控制系统时，以更少的交互建立准确的动作后果预测，并利用这种预测显著降低新技能的学习成本？

这至少包含三个可以验证的阶段：动力学知识迁移、目标系统快速适应、预测支持决策。

### 5. 最值得做的实验，可能不是骑车成功率最高的实验

我最希望看到的实验是：

让两个具有相同机器人本体的模型进入一个完全陌生的骑车环境。

一个模型拥有先前运动任务形成的动力学经验，另一个没有。

在只允许少量真实交互的条件下，观察两个模型怎样从第一次尝试逐渐学会控制。

然后进一步比较：

- 只有历史记忆是否足够；
- 显式 WM 是否提供额外收益；
- WM 的预测准确性与学习效果是否一致；
- 什么样的源任务最值得学习；
- 如果更换自行车，这些知识还能否复用。

**如果能系统性地回答这些问题，骑自行车就不只是一个展示机器人运动能力的任务，而可以成为研究通用运动技能习得、动力学知识迁移和 World Model 有效性的实验平台。**

这也是我认为这条研究路线最有潜力的地方。
