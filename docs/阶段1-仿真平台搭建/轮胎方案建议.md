# 轮胎方案建议

依据[轮胎基准测试](轮胎基准测试.md)，主模型已采用**192×24采样的单凸圆冠外包络＋MuJoCo软接触**，384×24保留为内存中的较高精度对照。项目仅保留一套生产配置。

圆冠保留270 mm外半径、36 mm总宽；几何需避免圆柱平胎面的横向支撑假稳定。圆柱基线、分段胶囊环和凸包方案都在内存中对照，不新增多套生产配置。

## 为什么调整推荐

96段胶囊环能够避免小扰动自稳，但分段交界的接触切换仍带来脉动。在CPU基准中，192×24单凸包比96段胶囊环更快、滚动高度波动略小，原始接触力波动约减半，因此采用192×24单凸包开展后续验证。

这不是训练轮胎的最终验收：需要补截面采样收敛、侧倾/侧滑、载荷、步长、人车干涉和GPU吞吐检查。圆冠凸包会填满轮心，不能拿它验证轮辐间隙等内部交互。

第一轮对照保持质量、惯量、摩擦和接触柔顺性一致；几何验证后，再标定轮组惯量和滚阻。软接触不能替代胎冠几何，也不自动模拟橡胶形变。当前轮胎显示与碰撞使用同一网格；后续可单独增加不参与碰撞的轮辐等装饰。

复现命令：`uv run --locked python -I -m bicycle_sim.cli.benchmark_tires`。

## 如何理解192×24与软接触

![圆冠轮胎采样和凸包示意](../output/phase1/rounded_tire_adoption/tire_explained.png)

沿车轮圆周选192个位置，在每个位置的小圆截面上选24个点，共4608个输入点。对这些点取凸包，得到一个边缘圆润的薄圆盘；轮心会被填满。每轮只有一个碰撞体，采样点不是独立碰撞体，也不是弹簧节点。胎冠仍是有限多边形近似，并非解析圆弧。

圆冠让轮胎横向接地处呈弧形，减小平胎面造成的侧向支撑。软接触由`solref=[0.02,1]`与`solimp=[0.9,0.95,0.001,0.5,2]`控制接触约束的响应；0.02秒是求解器时间常数，不能直接解释为橡胶刚度。碰撞体仍为刚体，不模拟充气、胎体弯曲或真实接触斑。

接入后26项回归测试通过；重新求解骑姿并检查25相位×9转向角，前部净空查询均达到50 mm截止上限，初始双手无穿透。小倾角测试确认0.1°无控制扰动会继续增大并倾倒。以上不等于机器人承重骑行已通过。
