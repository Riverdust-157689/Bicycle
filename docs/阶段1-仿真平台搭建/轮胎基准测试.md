# 圆冠轮胎基准测试

## 测试结论

胶囊环能消除当前圆柱轮胎的小角度自稳，但48段滚动脉动明显，96段仍有瞬时接触力波动。单个圆冠凸包外包络提供了更好的CPU成本/平顺性折中，建议将192×24方案作为下一轮验证重点，384×24作为较高精度对照；不直接把96段胶囊环定为训练轮胎。

本轮比较实验执行时，主模型、车辆尺寸、配置、依赖和生产资产均未修改，比较几何仅在测试进程内构造。实验结果写入被Git忽略的output目录。随后已按此结果将192×24圆冠凸包接入主模型，见[轮胎方案建议](轮胎方案建议.md)。

## 条件与方法

- MuJoCo 3.11.0，原生CPU。当前会话nvidia-smi返回9，GPU测试未执行。
- 7种几何：圆柱、48/96/192段胶囊环、96/192/384圆周采样×24截面采样的单凸包外包络。
- 保持外半径270 mm、总宽36 mm、质量、惯量、摩擦和接触柔顺性一致。每个胶囊环有多个碰撞体；每个凸包轮胎只有一个碰撞体，但仍有多面体离散误差。
- 小角度测试：完整单车、静止、无控制，从0.1°和1°倾斜开始，运行3秒，记录首次超过30°的时间。
- 滚动测试：单轮导轨夹具，限制侧倾和俯仰，仅允许前后/上下移动及车轮自转；使用前后牵引速度反馈。它只测接触平顺性，不代表自行车自平衡。
- 每轮总载荷质量4.5和21.697 kg，目标速度0.5/2.5/4.0 m/s，物理步长2/1 ms，共84个滚动工况。21.697 kg只是总质量均分的对照载荷，不是实际前后轮载荷分布。
- 滚动先静置0.5秒，再运行3秒并统计最后2秒。报告保存实际平均速度，目标2.5 m/s时各方案实际约2.44～2.50 m/s。
- CPU耗时另测：单车相同初始姿态，预热后重复10个1秒模拟区间，以原生批量mj_step计时，排除Python逐步采样开销，取中位数。表中耗时不含G1、不含渲染，不是GPU或完整训练吞吐。单轮滚动夹具的独立耗时另存JSON。

## 代表性结果

下表滚动指标采用每轮21.697 kg、目标2.5 m/s、1 ms步长。CV为标准差/均值；20 ms平均相当于50 Hz控制周期的非重叠均值，不能抹掉原始接触力波动。

| 方案 | 单车CPU步耗时 μs | 高度峰峰值 mm | 原始法向力CV | 20 ms平均法向力CV |
| --- | ---: | ---: | ---: | ---: |
| 圆柱基线 | 7.25 | 0.000 | 0.0% | 0.00% |
| 48段胶囊环 | 10.42 | 0.302 | 89.8% | 16.00% |
| 96段胶囊环 | 13.25 | 0.125 | 50.4% | 4.53% |
| 192段胶囊环 | 21.43 | 0.084 | 33.3% | 2.61% |
| 96×24凸包 | 9.02 | 0.192 | 51.0% | 5.24% |
| 192×24凸包 | 10.89 | 0.109 | 25.6% | 2.46% |
| 384×24凸包 | 14.74 | 0.048 | 12.8% | 0.80% |

圆柱平顺但有假稳定，不可仅凭其波动小而判定正确。0.1°倾斜时，所有圆冠候选约1.53～1.56秒超过30°，圆柱3秒内未超过；1°时圆冠候选约0.98～1.00秒超过30°。所有滚动工况状态有限、无MuJoCo求解警告，但这不等于轮胎物理已辨识。

## 推荐与边界

192×24凸包在本轮CPU单车基准约比96段胶囊环快18%，滚动高度波动略低，原始接触力CV约减半。384×24进一步降低波动，代价是更多几何查询工作。由此修正上一轮“先选96胶囊环”的暂定建议：先验证单凸圆冠外包络，再决定训练用模型。

下一步仍需：截面采样数收敛、侧倾接触/侧滑、不同负载及步长收敛、人车干涉和GPU吞吐。凸包填满轮心，不适用于检查轮辐间穿越等内部交互；主轮径与胎宽不变不代表人车交互已自动通过。完整骑行与真实轮胎对应性未验证。

```bash
uv run --locked python -I -m bicycle_sim.cli.benchmark_tires
```
