# 当前设计与验证状态

2026-11-18，车辆几何方案已确认。项目内只保留`configs/bicycle_v0.json`这一套设计参数。

## 确认方案

坐标约定：x向前、y向左、z向上；长度单位为米。

| 项目 | 当前参数 |
| --- | --- |
| 车轮半径／轴距 | 0.27／0.90 |
| 中轴位置 | (0.40, 0, 0.34) |
| 座面中心 | (0.24, 0, 0.77) |
| 握位中心 | (0.69, ±0.22, 1.02) |
| 握持段长／半径 | 0.14／0.014 |
| 曲柄长度／踏板中心横向偏置 | 0.11／±0.14 |
| 转向轴 | 偏竖直约11.36°，机械拖距0.04 |
| 转向范围 | ±0.35 rad |
| 传动 | 后轮角=2×曲柄角，理想双向耦合 |
| 初始骑姿 | 骨盆参考高于座面0.17，腰部关节参考0.45 rad |

横把直接接到转向立管，头管外形与实际转向轴一致。曲柄由中轴横段、曲柄臂、外伸踏板轴组成同一刚体；左右踏板各有独立轴承，折弯处不加关节。自由单车无后轮驱动执行器。

原始G1＋双手资产共43个执行器，`nq=50`、`nv=49`，质量约34.394 kg。单车质量假设9.0 kg，几何变化时重算等效惯量，尚未进行实车参数辨识。

## 已完成验证

- 本项目独立uv环境、锁文件及原生MuJoCo导入检查通过；EGL离屏渲染通过。
- 单车生成确定性、质量/惯量、轮地接触、曲柄传力、2:1传动及步长敏感性检查通过。
- 初始双手掌心向下，手指展开，实际碰撞体到握把间距约0.0585 mm，无手指/腕部穿透；下移机器人10 mm的负向测试能够检出穿透。
- 24个等分踩踏相位加闭环终点、三个转向角的位置可达性检查：足底最大误差约1.63 mm，手部目标点最大误差约0.0017 mm。
- 25相位×9转向角的前部净空检查通过；腿脚和曲柄/踏板间距查询均不低于50 mm。查询截止为50 mm，这只是下界，不代表精确最小净空。
- 14项回归测试通过。

肘关节数值采用G1原始关节坐标，不能直接解释为人体屈曲角；IK遵守原模型限位，不添加“角度必须为正”的限制。
