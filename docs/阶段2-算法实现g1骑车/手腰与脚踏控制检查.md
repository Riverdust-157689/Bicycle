# B 的手、腰与脚踏控制检查

日期：2026-11-19。本次检查当前辅助连接实验，未增加腰部或手指的策略动作；策略仍只有双臂14维位置偏移。当前依赖已安装，49项CPU测试通过，包括skrl PPO/SAC网络更新测试；不代表GPU物理已验收。

## 实际控制权限

| 部位 | 当前控制 | 策略权限与限制 |
| --- | --- | --- |
| 双臂含腕部 | 14个位置PD目标偏移 | 策略控制肩、肘、腕，不含手指 |
| 腰部3轴 | 固定目标PD；偏航0、侧倾0、俯仰0.45 rad | 不在动作里，但腰部位置与速度在观测里；不是无控制自由摆动 |
| Dex3双手14个手指关节 | 固定初始张开手型的PD目标 | 未学抓握，未设置包握轨迹，也没有由策略调节握力 |
| 掌心—握把 | 每手一个理想局部点连接 | 限制连接点相对位置，不焊死手掌姿态；可以传递拉力和推力，不能当作真实摩擦抓握 |
| 双腿12关节 | 实际曲柄相位参考＋带参考速度的PD跟随 | 无RL动作，会做正功或负功；不应称为纯被动腿 |
| 左右踏板平台 | 各自独立无界转轴，无执行器、无锁角等式 | 可相对曲柄转动；不是和曲柄固连 |
| 曲柄 | 有限力矩速度伺服 | 设定踏频；既可驱动也可制动，不能假定总是唯一动力来源 |
| 骨盆—车架 | 局部座位焊接 | 当前辅助，限制骨盆相对车架运动，但不连接世界，不阻止腰部关节运动 |

腰部位置增益为500 N·m/rad，编译出的偏航／侧倾／俯仰速度增益约28.20／38.01／38.22 N·m·s/rad，关节力矩有原模型限幅。保持目标并不意味着每个物理步强制腰角等于目标；受力时仍会有跟踪误差。

非策略关节由确定的PD控制并且状态可见，本身不构成“失控干扰”。固定腰部目标会限制主动重心调节，当前应称为上肢转向平衡。若目标扩展为腰臂协同，建议下一步先加入小范围腰部侧倾和俯仰残差，偏航维持PD；扩大动作空间可能增加探索难度，不能保证必然提高学习效率。本次未改变这一实验边界。

## 查出的脚踏问题与修正

原G1 locomotion碰撞模型在足底只有前后四个小球，足底中央没有连续碰撞面。以足底中心对齐小踏板时，踏板可能落在四球之间，运动学IK“脚在踏板上”并不保证碰撞上实际踩住。

修正只发生在B的模型适配层：每只脚增加连续底面箱体，底面高度与原四球最低点一致，平面范围覆盖原四球接触范围（中心`[0.035,0,-0.025]`，半尺寸`[0.09,0.035,0.01]`）。不修改机器人原始资产、外观、质量、惯量或已确认的车架。

连续碰撞面补上后，单纯位置目标跟随暴露了第二个问题：原生位置伺服中的`−kv*dq`会阻碍参考姿态运动，腿部拖慢曲柄。改为标准的参考速度PD：

```text
dq_ref = (dq_ref/dphase) * measured_crank_velocity
ctrl   = q_ref + (kv/kp)*dq_ref
原生力矩 = kp*(ctrl-q) - kv*dq
         = kp*(q_ref-q) + kv*(dq_ref-dq)
```

这里的斜率来自同一分段线性相位表，每个物理子步更新；不增加独立相位时钟，不把踏板锁水平，不直接覆盖腿部或踏板状态。速度补偿量与位置目标一起接受原有关节／伺服限制。配置字段`leg_velocity_feedforward`明确记录是否启用；旧run缺少此字段时按原来无补偿解释。

## 固定台架结果

测试车架固定、车轮离地；保留实际B的局部座位／掌把连接、腿部PD和曲柄速度伺服，无策略动作。持续12秒，除总转数和累计功外，统计去除前2秒启动段。曲柄目标3.704 rad/s。

| 设置 | 曲柄平均速度 | 左／右接触力>1 N比例 | 足底与踏板参考点距离RMS（左／右） | 最大足底—踏板法向夹角 |
| --- | --- | --- | --- | --- |
| 原四球碰撞、纯位置跟随 | 2.661 rad/s | 35.8%／37.9% | 22.1／21.8 mm | 36.6° |
| 连续足底、纯位置跟随 | 1.094 rad/s | 100%／100% | 8.8／8.1 mm | 0.20° |
| 连续足底、参考速度PD | 3.824 rad/s | 99.84%／99.88% | 5.3／5.4 mm | 0.49° |

参考点距离不是碰撞穿透深度；接触力阈值比例不是严格的无间隙率。最后一项12秒转动7.17圈，平台相对曲柄的转角跨约38 rad，明确没有锁定相对角度。正常水平放置时，踏板相对曲柄应近似反向转动，抵消曲柄旋转后才能适应足底。

在最后一项中，腰部偏航／侧倾／俯仰最大跟踪误差约0.049／0.025／0.167°，均无力矩饱和；手指最大偏移约0.0042°，理想掌把连接峰值反力约18.3 N。以上只验证名义姿态下的台架响应，不代表策略大幅摆臂、腰部扰动或GPU中也保持同样误差。

最后一项累计脚对踏板接触功约+24.5 J，曲柄伺服功约−10.4 J。这说明参考速度PD下双腿也会向踏板供能，曲柄伺服部分时间在制动。不能把该实验称为机器人自主学会驱动，也不能说全部能量都来自电机。

## 复现与范围

```bash
uv run --locked --extra training python -I -m bicycle_sim.cli.audit_rider_following
# 连续足底但不补偿参考速度，用于对照：
uv run --locked --extra training python -I -m bicycle_sim.cli.audit_rider_following \
  --no-leg-velocity-feedforward --output output/phase2/rider_following_position_only
```

报告与逐步数据默认输出到`output/phase2/rider_following_audit/`。本次比较报告另存于`rider_following_continuous_sole/`与`rider_following_velocity_ff/`，旧四球结果仅为历史诊断，不保留为生产模型分支。

本次修正不改变14维动作及130维观测，但改变了B的接触和随动动力学。旧B检查点不能与修正版直接混作同一物理设置的实验；如已有训练，应保留旧run配置并以新目录重新训练。当前仍待GPU自检、自由骑行及策略运动下的接触验证。真实Dex3包握、受限抓握力和腰臂协同尚未实现。
