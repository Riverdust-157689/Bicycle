# 自然抓握SAC：8M与16M训练结果

本文报告实验B的上半身20维策略，双腿不由策略控制；不能将其平衡结果作为实验C全身主动踩踏的验证。 实验编号及历史文件名对应见[实验划分与结果索引](实验划分与结果索引.md)。

检查日期：2026-11-20。三轮均已正常完成，环境配置与记录的源码哈希一致；16M轮源码及uv.lock也与当前工作区一致。它们是不同预算的训练运行，不能把三条曲线拼接成连续训练，也不是多个独立种子的统计验证。

## 平衡学习出现突破，但末尾退化

下表“近期”均指最近1000个已结束回合。训练使用SAC随机采样动作，尚未进行冻结策略的独立评测。

| 交互预算 | 结束时近期平均时长 | 结束时近期20秒生存率 | 训练中最佳近期平均时长 | 训练中最佳近期20秒生存率 |
| --- | ---: | ---: | ---: | ---: |
| 1,048,576 | 1.441秒 | 0% | 1.596秒 | 0% |
| 8,388,608 | 1.892秒 | 0% | 2.426秒 | 0% |
| 16,777,216 | 7.584秒 | 24.0% | 19.969秒 | 99.8% |

8M轮最长已完成回合7.8秒，尚无撑满20秒的回合。16M轮在11,123,200次交互的日志窗口首次记录成功；13,350,400时近期成功率达到50.1%；15,206,400时达到90.3%；16,038,400时达到99.8%。成功率随后回落，最终24%。最佳窗口是事后根据训练日志选择，不能直接作为独立测试成绩。

16M轮全程累计成功率仅2.55%，包含前期大量失败，不能代表训练后期的策略水平。反过来，最终策略也不能用历史99.8%的峰值代替评测。训练中每2000个向量步保存检查点，`agent_126000.pt`对应16,128,000次交互，当时近期成功率98.9%；它是接近峰值且实际存在的候选文件。`agent_124000.pt`对应15,872,000次交互，当时94.2%。

## 双手接触显著减少

16M轮峰值窗口的双手同时有受力手指接触比例约0.92%，结束窗口约0.66%；后者六指受力比例28.15%，折合每个控制步平均约1.69个手指组受力。该指标按控制步及并行环境统计，不是“保持抓握的回合占比”。它只统计本侧手指与本侧车把，不能排除手掌等其他部位仍在接触。

这表明成功平衡并未伴随持续双手指端握持。可能是单手转向，或身体/双臂经座位连接传递反作用来平衡，也可能还有其他接触方式。仅凭现有聚合日志无法区分，不应直接认定策略作弊或实现了单手骑行。闭合量末期回升至0.925，接触仍很少，说明闭合命令不等于手仍在车把上。

当前任务保留座位连接、外部曲柄驱动、腿部相位参考和固定腰部参考。20秒生存也未单独要求最低速度或目标跟踪，因此还需核查速度轨迹，不能把生存率直接解释为自主踩踏与受控行进。当前奖励没有把持续双手抓握设为成功条件，不能据此把学习到其他平衡方式一概判为错误。

## 下一步：冻结评测并录制GPU轨迹

先保持模型、奖励和算法不变，比较接近峰值的检查点与最终检查点。使用相同新种子、128个环境、每个环境只统计首个回合，避免重置次数不同影响对比。下面同时保存一条实际GPU轨迹，之后可渲染视频。

```bash
uv run --locked --extra training python -I -m bicycle_sim.cli.probe_rider_gpu \
  --controller policy --device cuda:0 --num-envs 128 --steps 1100 --seed 20000 \
  --source-run runs/b_contact_sac_pilot_seed42_tran16777216 \
  --checkpoint runs/b_contact_sac_pilot_seed42_tran16777216/logs/checkpoints/agent_126000.pt \
  --first-episodes-only --record-only \
  --output output/phase2/b_contact_sac_16m_peak_probe

uv run --locked --extra training python -I -m bicycle_sim.cli.probe_rider_gpu \
  --controller policy --device cuda:0 --num-envs 128 --steps 1100 --seed 20000 \
  --source-run runs/b_contact_sac_pilot_seed42_tran16777216 \
  --first-episodes-only --record-only \
  --output output/phase2/b_contact_sac_16m_final_probe
```

两条命令均不更新网络；`--record-only`只是关闭原反馈控制器的验收门槛，仍保存回合结果和轨迹。首轮用于检查确定性策略的成功率、速度、车把转角、左右手接触力与双臂运动；之后再决定是否补充更多种子、单手/双手任务约束，或提高动作稳定性。暂不根据训练末尾退化直接修改SAC超参数，也不立即扩大训练预算。

对比曲线保存在`output/phase2/b_contact_sac_long_training_review/learning_curves.png`。其中接触比例为各日志窗口的控制步统计，生存率为近期1000个已结束回合统计，两者时间窗口不同。

## GPU冻结策略评测与回放

用户已执行上述两组命令，种子20000，每组128个环境，仅统计首个回合，使用确定性均值动作：

| 检查点 | 20秒生存率 | 平均回合时长 | 回合结束时平均前进速度 |
| --- | ---: | ---: | ---: |
| agent_126000.pt | 72/128，56.25% | 12.282秒 | 1.928 m/s |
| final.pt | 128/128，100% | 20秒 | 1.871 m/s |

因此，训练末尾随机采样回合成功率下降，并不能直接认定最终确定性策略退化；当前最终策略在本组测试中反而更好。探索噪声是值得排查的因素，尚未用同状态、不同噪声的受控对照确认原因。这组评测仍只有一个种子与较窄的初始分布。

用户观察到右手举起、左手两指夹把。保存的第0号环境轨迹与之吻合：2秒后，最终策略左拇指和左中指法向合力均值约17.56 N、41.15 N，其受力接触时间比例约80.8%、99.1%；左食指和右侧三个手指组均未记录到本侧车把受力接触。两指并非每一刻都同时接触，数据也不能单独证明完整力闭合。

最终策略该条轨迹2秒后前进速度均值1.933 m/s、平均侧倾约2.93度、平均转角约-7.85度，20秒内航向累计变化约-314度；峰值附近检查点对应轨迹累计约-396度。它们呈持续同向绕行，而非直线或目标航向跟踪。这符合当前未规定航向目标的自由行进平衡任务，不能仅因绕圈判失败。

右臂抬起可能改变质心或通过运动参与平衡，但当前只有轨迹观察，未做固定右臂等因果对照，不能断言其具体作用。下一步优先保留该成功基线，延长评测时长并检查多种初始条件；若转向目标跟踪成为下一任务，再增加目标条件，而非立即用姿态惩罚强制双手握把。
